A

怎麼稽核這份進度表

給你的

這份表的每一列都有「產出 / 證據」欄，寫的是檔案路徑而不是描述 —— 因為勾選框可以造假，檔案不行。稽核方式：

  1. 對照「產出」欄的路徑，確認檔案真的存在且內容合理。
  2. 每個 gate 區塊的指令直接複製到 terminal 跑，看輸出符不符合描述。
  3. 任何我標成「完成」但你跑指令跑不出來的，就是我報錯了 —— 請直接指出。

這個做法刻意跟 harness 本身的設計對齊：自報的欄位不可信，ledger 才可信。 rep_84 的教訓就是一個 agent 可以宣稱它跑了 extract_window 而其實沒有 —— 同樣的懷疑該套用在我身上。

F

建置過程中的發現

需要你知道的

1 · V0 的檢查項數在兩個 harness 之間不一致

Pi 的 run 有 25 項檢查，OpenCode 只有 23。多出來的是 sampling_matches_config 與 sampling_pin_evidence —— 因為 Pi 需要 sampling extension 才能 pin 住 temperature/top_p，而那個 extension 本身也要被驗證。

這在防禦上說得通，但意味著兩個 harness 並不是被同一組檢查衡量的。 我原本的規劃文件寫「23 項檢查」是錯的，UI 已改成從 bundle 讀實際項數； 任何寫死 23 的分析都會默默把每個 Pi run 標錯。如果之後要主張 fairness，這點要先講清楚。

2 · 已對 phase 0 加了一個 additive flag

scripts/new_run.py 新增選用的 --tasks-file， run_opencode.sh / run_pi.sh 新增 PHASE0_TASKS_FILE 傳遞。 預設行為完全不變。

理由：demo 題目與 L1 的自訂問題都不在凍結的 benchmark 清單裡。沒有這個 flag， 就只能把 demo 題目附加到 data/agent_inputs/phase0_tasks.jsonl， 那會把 demo 內容混進實驗的 task 清單，任何走訪該檔的批次都會誤抓。 這是動到 phase 0 的改動，需要補一筆 decision 記錄（併入 L0.7）。

3 · 一個真實 run 打破了匯出器的假設

rep_81 的 agent 把 extract_window 的 --output 也指向 artifacts_crv，覆蓋掉自己的 coarse 產出 —— 沒有 frames/、沒有 frames_index.json，只剩 dense window 的 w_*.jpg。 匯出器原本假設只有 coarse 佈局，直接匯出 0 張 frame。

已修正為同時吃 window.json、三種 frame 落點，並保留「被引用但不在任何索引裡」的孤兒 frame。 這同時也是一個值得展示的 agent 失敗模式。

4 · 一次無法重現的啟動卡死

首次批次執行時，兩個 harness 都卡在 session 建立（OpenCode 的 log 停在 init，Pi 的 event stream 0 行），雙雙撞到 timeout。 磁碟、記憶體、inotify、模型服務全部正常（coder 回應 0.185s）。

執行 pkill -u phase0agent 清掉殘留 process 後，同一個 sample 連續兩次成功。 無法重現，所以無法斷定根因。批次腳本已改為先清殘留、遇 timeout 立即中止， 避免 30 個 run 各空轉 5 分鐘。如果再次出現，這是需要往下追的線索。

5 · 我自己犯了這個 demo 在講的那個錯

D3.6 的 gold 守衛我原本標成完成，依據是我跑了一個簡化版的 grep， 而不是 workflow 裡真正那一行。實際執行後才發現：那個守衛掃整個 checkout， 因此會擋下它自己的原始碼 —— tools/export_run.py、tools/validate_bundle.py、 live/sanitize.py 與 workflow 本身都含有 phase0_gold， 正因為它們是阻擋它的程式。那個 CI 從來不可能通過。

已改為掃 app/dist（真正會被發布的產物），並比照 tamper_tools 做了正反面驗證：對真實建置產物通過，植入一筆參照後確實被抓到。

值得記下來的不是這個 bug，而是它的形狀：「我跑了一個像那樣的檢查」不等於 「我跑了那個檢查」 —— 正是 rep_84 的 tool_trace 與 ledger 不符的同一種落差，只是發生在我這一邊。 這也說明為什麼這份稽核表的「產出／證據」欄要寫檔案路徑，而 gate 要附指令給你自己跑。
